# post-lab board

This repo has a post-lab board in `.post-lab/`: a canvas the user opens with `npx post-lab`. You work on it only by editing its files; an open board shows each change as soon as the file is saved.

Before reading or changing the board, read `.post-lab/README.md`. It is the full guide to the file format and always matches the installed post-lab version.
